## 視覺與播放決定

punkcan.art 收藏藝術檔案，PUNKCANVERSE 放映電影，並介紹臺灣民間信仰書系（2026-11-22 起）。首頁以黑色為底，片單的顏色取自影片本身。中文片名在前、英文片名在後，兩種語言的頁面都保留這個順序。

- **色條**以鏡頭為單位。每個偵測到的鏡頭佔一道色帶，顏色取自鏡頭平均色，寬度反映鏡頭長度。整部片的色條長度則依片長相對於片單中最長的作品縮放。素材腳本另產生取樣圖 `barcode.png`，畫面上的色帶由 `film.json` 的 `shots` 繪製。
- **預覽與播放**可用指標或左右方向鍵沿色條預覽劇照。進入電影頁後可選定起播時間，再按播放載入 YouTube 嵌入播放器。
- **播放版本**在 11 月 8 日定案為 YouTube。當時選用的英文字幕版是帶有影展浮水印的 Flick 投件版。日後更換版本時，在片單更新該語言的影片 ID。
- **字型**依電影樣式表指定的字型順序，使用裝置可用的字型。原案中的字型自架與子集化尚未實作。[電影樣式](../web/films.css)

語言路徑、台灣用語和電影首頁分別隨三個 PR 合併。[語言路徑 #17](https://github.com/punkcanyang/PUNKCANVERSE/pull/17) · [繁中用語 #18](https://github.com/punkcanyang/PUNKCANVERSE/pull/18) · [電影首頁 #19](https://github.com/punkcanyang/PUNKCANVERSE/pull/19)

## CPP 與比賽清單正式格式（2026-11-10）

兩個頁面共用收錄日期、名稱、主辦方、一句摘要、官方連結；頁首標示整份清單的整理日期。收錄日期取自 Notion 的「首次发现」，按日期降冪排列，同日依名稱穩定排序。修改說明或延長截止日只更新該筆資料；新一屆比賽另列一筆。正式版沿用英文根路徑與繁中 `/zh/`。雙語正式頁面使用同一份 [公開清單資料](../content/opportunities.json)。以下保留最初的繁中樣稿作為版型參考。[CPP 樣稿](mockups/opportunities/cpp.html) · [比賽樣稿](mockups/opportunities/competitions.html)

| 清單 | 第一眼可見 | 展開後呈現 |
| --- | --- | --- |
| 創作者合作計畫（`/cpp/`） | 申請門檻、要交付的作品或發文頻率、入選回饋。循環招募或固定梯次跟著申請方式標示。 | 指定工具、跨平台發文、浮水印、授權與各方案的差異。 |
| 比賽與徵件（`/competitions/`） | 可投的作品、下一個截止日及階段、報名費與主要獎項。多階段徵件同時標出最終截止日。 | 原始截止時間與時區、其餘梯次、規格、地區資格、發行條款。 |

期限精確到時間時，同列官方時區與台北時間；只有日期時保留日期精度。區別現金、平台點數與訂閱回饋，也把免費報名所附的授權條件放在費用旁。未公布的關鍵條件可標「官方未載明」。期限已過的項目標「已截止」，保留收錄順序。

Notion 的「创作者计划」對應 CPP，「AI 征件／比赛」「生成艺术比赛」「电影节」對應比賽頁，「其他」逐筆判斷。公開摘要採用已核對的主辦方資料，個人報名進度、作品適配筆記與內部連結留在 Notion。兩頁是獨立的徵件資訊，與原創教學各有入口。

## 搜尋設定（2026-11-10）

| 頁面 | 設定 |
| --- | --- |
| 電影頁 | 標題為「片名 · 類型 · Punkcan」。分享圖用該片的海報劇照。頁面附 `VideoObject` 與麵包屑資料。 |
| 首頁與關於頁 | 首頁附 `WebSite`、`Person` 與片單資料，關於頁附 `ProfilePage`。關於頁列出片單，並連到 X、punkcan.art 與信箱。 |
| CPP 與比賽清單 | 標題與 H1 加上「AI」。搜尋描述由資料產生，列出前三個主辦方、涵蓋內容與整理日期。每筆的 H2 有固定錨點，可直接連到單筆。 |
| 作品頁 | 沒有作品時標為 `noindex`，不列入 sitemap。有作品後自動恢復，並出現在主導覽。 |
| Sitemap | 清單頁的 `lastmod` 取整理日期，電影頁取上映日期。 |

`content/films.json` 的每部片可加 `published`（`YYYY-MM-DD`，年份須與 `year` 相同）。目前兩部片都還沒填，所以 `VideoObject` 沒有 `uploadDate`，Google 的影片搜尋結果需要這個欄位。結構化資料放在 `<body>`，`<head>` 只保留兩段分析用的行內腳本。[結構化資料](../lib/seo.mjs)

本機建置與正式站抽查的範圍、日期及結果另見[部署檢查紀錄](deployment-checks.md)。
