# PUNKCANVERSE 改版規劃（草案）

日期：2026-11-07
狀態：待確認，尚未動程式碼

## 定位

網站從「提示詞收藏」改為 Punkcan 的 AI 創作作品集，次要內容是 AI 學習技巧的分享。首頁只呈現作品；提示詞庫和學習內容照常上線，但首頁不放入口連結。

## 已確認的決定

| 項目 | 決定 |
| --- | --- |
| 首頁 | 只放作品，不連到提示詞庫與學習內容 |
| 影片 | 全部放在 YouTube，網站只嵌入 |
| 語言 | 英文、繁體中文；停用日文 |
| 視覺 | 全面重新設計，不沿用「深夜片場 · 影印批注」 |

## 網站地圖

```
/                     首頁：作品牆
/works/<slug>/        作品詳情：影片或圖片、說明、製作拆解
/learn/               學習文章列表（首頁不連）
/learn/<slug>/        單篇文章
/prompts/...          提示詞庫，網址與內容不變（首頁不連）
/about/  /contact/    關於、聯絡
/privacy/ /terms/ /affiliate-disclosure/ /takedown/   政策頁，內容沿用
```

`/tips`、`/regions` 先保留原網址，之後視情況併入 `/learn/`。

## 作品資料格式

延用 `content/works.json`，新增嵌入型媒體：

```json
{
  "film": "wind-of-cijin",
  "embeds": {
    "zh-Hant": { "provider": "youtube", "id": "UnGmCoPDIn8" },
    "en": { "provider": "youtube", "id": "MtAeWTZZLWg" }
  }
}
```

- 全部從 YouTube 播放（2026-11-08 決定，不用 Vimeo）。`/zh/` 片頁嵌中文版，英文片頁嵌英文字幕版。目前的英文字幕版是 Flick 影展投件版，畫面帶影展浮水印；若之後上傳無浮水印的英文版，只要換 ID。
- `provider` 先只允許 `youtube`，建置時檢查 ID 格式；四支影片的 oEmbed 都回 200，可以嵌入。
- `film` 指向 `web/img/films/<slug>/`，封面、色條與逐格畫面都從那裡讀；沒有 `film` 時退回平台縮圖，也不顯示色條。
- 片名分 `zh-Hant` 與 `en` 兩欄，兩種語言的頁面都會同時顯示。
- 頁面先顯示封面圖，點擊後才載入播放器（YouTube 用 `youtube-nocookie.com`），首屏不載入任何第三方腳本。
- 每件作品可加選填欄位 `making`（Markdown），記錄使用的工具、提示詞與步驟，並可連到相關的 `/learn/` 文章。
- 作品另加 `tools`、`year`、`tags`，供作品牆篩選。

## 學習文章

- 以 Markdown 撰寫，放在 `content/learn/<slug>.<locale>.md`，前置資料含標題、日期、分類、標籤、摘要。
- 兩種主要類型：教學長文、作品幕後拆解。
- 某語言沒有譯文就不產生該語言的頁面，hreflang 只列實際存在的版本。

## 語言

- 語言代碼改為 `en` 與 `zh-Hant`，HTML `lang` 為 `zh-Hant-TW`。
- 英文放根網址 `/`，繁體中文放 `/zh/`。x-default 指英文。
- 轉址（301，保留 query，由現有 `functions/_middleware.js` 處理）：
  - 舊英文 `/en/...` → 根網址對應頁 `/...`
  - 舊中文根網址 `/...`（例如 `/prompts/video/123/`）不轉址。同一路徑改由英文頁接手，頁面提供語言切換，hreflang 指向 `/zh/` 版本。代價是舊的中文書籤和搜尋結果會先落在英文頁，中文搜尋排名需要時間轉移到 `/zh/`。
  - 舊日文 `/ja/...` → 根網址對應頁 `/...`
- 現有簡體中文（介面字串約 1000 行、內容譯文、三份 tips）轉為繁體。先用 OpenCC（s2twp，含台灣用詞）自動轉換，再人工校對用詞。提示詞原文不轉換。
- 建置規則放寬：新內容可以只有一種語言；舊頁面維持兩語。
- 日文頁面從 sitemap 和 hreflang 移除，`data/i18n/ja.json` 等檔案移到封存目錄。

## 視覺方向（2026-11-08 定案）

樣板：`docs/mockups/e-director.html`。

定位是 AI 導演的作品集，背後是藝術家和創作者。punkcan.art 是藝術檔案庫，這個網站是放映的那一面，兩站是兄弟站。

概念：每部片拆成它的最小單位。全站只在這一處用力，其他地方保持安靜。

- 片單就是色條。每部片壓成一條色條，每半秒取一道整格平均色；色條長度等於片長。
- 滑過色條，上方投影畫面換成片中那一刻（逐格看）。投影畫面固定在上方，片單在下方捲動，兩者同時可見。手機用拖曳，鍵盤用左右方向鍵。
- 片頁的色條可以點：從那一刻開始播放（YouTube `start` 參數）。
- 沒有品牌色。底色是純黑（放映廳），頁面上的顏色全部來自影片。只有深色一套，不做亮色主題。
- 片名用台灣藝術電影海報的雙語排法：中文思源宋體（Noto Serif TC）大字，英文小字。英文站也顯示中文片名。
- 介面字體 IBM Plex Sans，與 punkcan.art 同一家族。
- 片頁依序是：雙語片名、播放器、色條、片尾字幕式的資訊（Directed by、模型、音樂、剪輯、片長、年份）、導演筆記、製作過程。
- 動態只有一處：首頁載入時色條由左往右展開一次；系統設定減少動態時不播放。
- 首頁的自我介紹由 Punkcan 本人撰寫。

字體要自架並做子集：思源宋體依每頁實際用字裁切，IBM Plex Sans 只取 Latin。保持無框架、無 npm 依賴、靜態輸出，部署照舊用 Cloudflare Pages。

### 色條與逐格畫面的產生

`scripts/film-frames.mjs` 從本機影片原檔產生：

```bash
node scripts/film-frames.mjs <slug> <影片檔> [--frames 16] [--width 960]
```

輸出到 `web/img/films/<slug>/`：`barcode.png`（每欄一格的平均色，長片上限 1200 欄）、`01.webp` 起的平均分布畫面（同時當封面）、`film.json`（片長、尺寸、取樣與每格時間）。影片原檔不進倉庫，播放仍走 YouTube。每部片 24 張畫面約 1.2 MB。
